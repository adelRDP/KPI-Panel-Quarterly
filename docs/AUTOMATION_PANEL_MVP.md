# نسخه پایه «پنل ارزیابی عملکرد»

تاریخ ایجاد: 2026-09-16

یادداشت 2026-09-19: این سند دامنه فرانت‌اند اولیه را توصیف می‌کند. بک‌اند محلی ارزیابی AI و ذخیره‌سازی مستندات فعالیت‌ها بعداً اضافه شده است؛ برای وضعیت جاری، `AI_EVALUATION.md` و README را ببینید. محدودیت احراز هویت و مجوزهای واقعی همچنان برقرار است.

## هدف نسخه

این نسخه یک نمونه اجرایی فرانت‌اند برای مشاهده ظاهر و جریان‌های اصلی پنل اتوماسیون هلدینگ است. هدف آن اعتبارسنجی تجربه کاربری پیش از انتخاب معماری سرور، احراز هویت و مخزن فایل سازمانی است.

## قابلیت‌های پیاده‌سازی‌شده

- داشبورد فارسی، راست‌چین و واکنش‌گرا
- نمایش خلاصه مستندات، کاربران، بارگذاری‌ها و موارد در انتظار بررسی
- فضای مستندات با جست‌وجو و فیلتر دسته‌بندی
- بارگذاری فایل تا سقف ۲۵ مگابایت
- نگهداری فایل‌های بارگذاری‌شده در IndexedDB مرورگر
- دانلود و حذف فایل‌های بارگذاری‌شده
- تعریف سطح دسترسی برای هر مستند
- ایجاد دعوت کاربر و تخصیص واحد و نقش
- فهرست کاربران و وضعیت دعوت
- ثبت و نمایش رویدادهای فعالیت
- تنظیمات پایه فضای کاری
- چیدمان سازگار با دسکتاپ، تبلت و موبایل

## محدودیت‌های این نمونه

- احراز هویت واقعی و حساب کاربری سروری ندارد.
- داده‌ها بین مرورگرها و دستگاه‌ها همگام نمی‌شوند.
- سطوح دسترسی فعلاً به‌صورت رابط کاربری تعریف شده‌اند و در سرور enforce نمی‌شوند.
- فایل‌های نمونه اولیه قابل دانلود نیستند؛ فقط فایل‌هایی که کاربر در همان مرورگر بارگذاری می‌کند Blob واقعی دارند.
- اعلان ایمیلی، گردش تأیید، نسخه‌بندی مستند و اتصال به Active Directory هنوز پیاده‌سازی نشده‌اند.
- این نسخه برای داده‌های واقعی یا محرمانه سازمانی مناسب بهره‌برداری نیست.

## اجرای محلی

از ریشه پروژه اجرا شود:

```powershell
node server.mjs
```

سپس آدرس زیر باز شود:

```text
http://127.0.0.1:4173
```

## تصمیم‌های لازم برای نسخه بعد

1. انتخاب روش ورود: Active Directory، Microsoft Entra ID، ورود پیامکی یا حساب داخلی.
2. تعیین مدل سلسله‌مراتب شرکت، واحد، تیم و مدیر.
3. تعیین ماتریس نقش و مجوزها برای مشاهده، بارگذاری، تأیید، ویرایش و حذف.
4. انتخاب محل ذخیره فایل: فضای ابری سازمان، SharePoint، MinIO/S3 یا فایل‌سرور.
5. تعیین گردش تأیید و انتشار مستندات.
6. تعیین سیاست نسخه‌بندی، نگهداری و حذف فایل.
7. انتخاب فناوری بک‌اند و پایگاه داده پس از مشخص شدن زیرساخت سازمان.
