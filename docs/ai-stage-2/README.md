## مبنای فعلی پروژه

بررسی روی کد محلی با HEAD برابر `642285b` و تغییرهای ثبت‌نشده موجود در رابط انجام شد. پیاده‌ساز باید وضعیت تازه را بخواند و تغییرهای کاربر را حفظ کند. ارزیابی فعلی `activity-review-v2` نمره آزاد تولید می‌کند؛ مسیر جدید باید جدا و نسخه‌دار باشد.

قواعد جدید `score-rules` درباره تأخیر، تحویل، اصلاح و انتخاب سیاست معتبر بخشی از مبنا هستند. پل فعلی `activityScore` از `finalScore` و در نبود آن از `qualityScore` استفاده می‌کند. قرارداد جدید نباید این قواعد را دور بزند یا دوباره جریمه کند.

ترتیب مرجع: درخواست جاری کاربر و AGENTS.md؛ وضعیت تازه پروژه و سیاست‌های واقعاً منتشرشده؛ این بسته برای مرحله دوم؛ اسناد قدیمی برای پیشینه. تعارض مهم گزارش و بخش مستقل کار ادامه یابد؛ پرامپت Word نمونه مرجع اجرایی نیست.
