# شاخص‌های داشبورد عملکرد (نسخه نمایشی)

این سند فقط مدل ساختگی داشبورد در 2026-09-20 را به‌عنوان سابقه نگه می‌دارد. مدل جاری از 2026-09-26 در [گردش پنل‌های فرد، مدیر، HR و مالی](PERSONNEL_WORKFLOW.md) تعریف شده است؛ وزن‌ها و محاسبه‌های این فایل مبنای UI فعلی یا پرداخت نیستند.

داشبورد فعلی فقط از داده‌های ساختگی `src/kpi-dashboard.js` استفاده می‌کند. مبالغ، عملکرد، حقوق و سقف‌ها واقعی یا مصوب نیستند و نباید مبنای پرداخت قرار گیرند.

| نمایش | تعریف در نسخه فعلی |
| --- | --- |
| عملکرد کل KPI | مجموع `وزن شاخص × درصد عملکرد شاخص` تقسیم بر مجموع وزن‌ها (۱۰۰). عدد میانی برای نمایش گرد می‌شود. |
| دریافتی KPI | مجموع `گردشدهٔ (سقف مبلغ هر شاخص × درصد عملکرد همان شاخص)`؛ ممکن است درصد تحقق مبلغ KPI با عملکرد وزنی تفاوت داشته باشد. |
| تحقق دریافتی KPI | دریافتی KPI ÷ مجموع سقف مبالغ شاخص‌ها. |
| سهم حقوق ثابت | حقوق ثابت ÷ حقوق نهاییِ محاسبه‌شده در همین مدل؛ این سهم، امتیاز عملکرد نیست. |
| حقوق نهایی | حقوق ثابت + دریافتی KPI، فقط طبق فرمول موقت نمایشی. |
| تحقق حقوق نهایی | حقوق نهایی ÷ (حقوق ثابت + سقف KPI). این نسبت فقط فاصله از سقف همین مدل نمایشی را نشان می‌دهد. |
| فاصله هر شاخص تا سقف | سقف مبلغ شاخص − مبلغ محقق‌شدهٔ آن. طول نوارها نسبت به بزرگ‌ترین فاصلهٔ همان ماه مقیاس می‌شود؛ مقدار پولی کنار هر نوار ملاک دقیق است. |
| ترکیب دریافتی KPI | سهم مبلغ محقق‌شدهٔ هر شاخص از کل دریافتی KPI؛ بخش‌ها در مجموع ۱۰۰٪ می‌شوند. |

در نبود سقف/مبلغ قابل تقسیم، نسبت نمایشی صفر در نظر گرفته شده است. نمودار روند زمانی عمداً وجود ندارد، چون دادهٔ تاریخی تعریف نشده است. پیش از اتصال دادهٔ واقعی و حقوق، تعریف شاخص، منبع/مالک داده، قواعد استثنا، نسخهٔ فرمول و کنترل‌های عدالت و کیفیت داده باید تصویب شوند.
