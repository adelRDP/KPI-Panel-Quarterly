# پنل مستقل ارزیابی فصلی

این پروژه از کد آزموده‌شدهٔ پنل ماهانه/فصلی منشعب شده، اما کد، مخزن Git، پایگاه داده، پیوست‌ها، حساب‌ها، صف AI و پشتیبان مستقل دارد. ارزیابی فقط یک بار برای هر فصل ثبت می‌شود. دوره‌های ماهانه در گردش فعال پذیرفته نمی‌شوند.

## اجرا

Node.js 24 یا جدیدتر و pnpm لازم است:

```powershell
pnpm install --frozen-lockfile
npm start
```

آدرس محلی: http://127.0.0.1:4273/ . برای اجرای مخفی ویندوز: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-panel.ps1`.
اجرای مستقیم `server.mjs` مسیر استاندارد این پروژه نیست؛ راه‌انداز اختصاصی جداسازی مسیرها و تنظیمات را اعمال می‌کند.

ورود اصلی و حساب‌های مستقل ادمین، مدیر و پرسنل در `.runtime/initial-access.csv` قرار دارند. این فایل محرمانه و خارج از Git است؛ رمزهای شخصی در اولین ورود باید تغییر کنند. رمزها در پاسخ چت یا گزارش رویدادها منتشر نشوند.

## آزمون

```powershell
npm test
npm run check
node scripts/check-quarterly-browser.mjs
```

آزمون‌ها از دادهٔ ساختگی و مسیرهای موقت استفاده می‌کنند. مدل واقعی فراخوانی نمی‌شود. اتصال محلی Codex اکنون با ورود تازهٔ مختص همین پروژه فعال است؛ اعتبارنامهٔ پروژهٔ اول منتقل نشده است. `npm run test:live` آزمون واقعی متن و اکسل با مصرف سهمیهٔ حساب، روی داده و پایگاه موقت اجرا می‌کند.

قواعد دوره، مبلغ، جابه‌جایی، مسیرها و محدودیت‌های استقرار در [راهنمای پروژهٔ فصلی](docs/QUARTERLY_PROJECT.md) آمده است.
